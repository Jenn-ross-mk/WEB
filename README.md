# Chevrolet Akar – Sitio web

Página temporal "Próximamente" que redirige a www.chevroletakar.com.ar.

Sitio estático (HTML + CSS), listo para publicar con GitHub Pages:
Settings → Pages → Source: "Deploy from a branch" → rama `main` (o la rama publicada), carpeta `/ (root)`.

- `index.html`: página principal
- `assets/`: imagen de fondo (WebP + JPG para la vista previa en Meta)
